# 任务二个人心得

通过本次任务，我知道了如何更加专业地利用 Claude Code 编写爬虫代码，也进一步了解了如何通过浏览器检查工具观察网页结构、定位网页元素，以及处理详情链接和 iframe 等内容。

在老师上课的实践部分，我后面跟着老师的步骤一步一步完成。在这个过程中，我发现提前配置好 Hooks 和 Skills 还是非常重要的。Skills 可以提前告诉 Claude Code 项目需要遵守的规范、使用的技术和完成任务的方式；Hooks 可以在代码修改完成后自动进行检查，帮助发现代码质量、类型和测试方面的问题。如果没有提前设置好这些规范和检查，程序出现问题以后，就可能陷入“报错、修改、再次报错、再次修改”的循环。

不过，配置也需要与自己的电脑环境相适配。老师使用的是 macOS，而我使用的是 Windows，因此部分 Hook 在 Windows 的 GBK 编码环境下出现了报错。解决这个问题后，我对 Hooks 的运行方式和 Windows 环境兼容问题也有了更直观的认识。

这次实践还让我觉得，有些代码修改就像是在不断“打补丁”。如果最开始的结构或者实现方式不正确，只针对每一次报错进行局部修改，可能会让代码越来越复杂。与其反复修补，有时还不如先重新梳理需求、错误原因和正确的实现流程，再让 Claude Code 按照清晰的规范重构或者重新生成相关部分。

总的来说，这次任务不仅让我完成了 Python 爬虫程序，也让我认识到：使用 Claude Code 时，不能只简单地让它生成代码，还需要先说清楚需求、网页结构、技术规范和验收标准，并在运行以后根据真实结果进行检查。只有这样，才能更稳定、更专业地利用 Claude Code 完成开发任务。
